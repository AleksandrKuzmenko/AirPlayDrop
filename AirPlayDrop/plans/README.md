## Dependency notes

- Characterization tests land first because the remaining work changes file handling, subprocess lifecycle, and media selection.
- Atomic output handling precedes validation and concurrency so no test or retry path can overwrite a user file.
- Media selection precedes the capability planner because selected tracks are inputs to the plan.
- The initial public release is source-first and requires a user-installed FFmpeg/FFprobe. Do not publish unsigned application binaries.

## Findings considered and rejected

- Mac App Store distribution: rejected for the initial release because the current external-process design and disabled sandbox require architectural work beyond the source-first alpha.
