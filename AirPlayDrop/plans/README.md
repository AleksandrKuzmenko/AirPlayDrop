## Dependency notes

- Characterization tests land first because the remaining work changes file handling, subprocess lifecycle, and media selection.
- Atomic output handling precedes validation and concurrency so no test or retry path can overwrite a user file.
- Media selection precedes the capability planner because selected tracks are inputs to the plan.
- The initial public release is source-first and requires a user-installed FFmpeg/FFprobe. Do not publish unsigned application binaries.
- Preferred languages land before external subtitles so embedded and sidecar tracks share one deterministic resolver.
- External subtitles land before synchronization so one typed selection model covers embedded and sidecar timing.
- Resume playback lands before timeline thumbnails because both touch playback time and transport UI.
- Late-night dialogue mode is independent of Plans 010–013 but must preserve the capability planner's standard audio path exactly.

## Findings considered and rejected

- Bundling FFmpeg in the initial release: rejected for now because signing, notarization, architecture coverage, and FFmpeg license compliance require a separate release-engineering decision.
- Mac App Store distribution: rejected for the initial release because the current external-process design and disabled sandbox require architectural work beyond the source-first alpha.
- Chromecast: rejected by the maintainer; AirPlayDrop remains focused on Apple TV and AirPlay.
- Phone remote: rejected by the maintainer; macOS remains the playback controller.
- Subtitle OCR: rejected by the maintainer; external subtitle support is limited to text formats.
- Atmos passthrough: rejected by the maintainer; the current compatible AAC stereo output remains the supported audio pipeline.
- Multiple persistent playlists: rejected by the maintainer; the playlist remains a transient work queue.
